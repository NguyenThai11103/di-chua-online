# Đi Chùa Online

Không gian chánh điện tương tác trên web dành cho những phút thư giãn và tĩnh tâm. Người dùng có thể ghi tên, gửi lời nguyện, dâng hương hoặc hoa sen, thỉnh chuông và nghe nhạc thiền ngay trên điện thoại, máy tính bảng hoặc máy tính.

Ứng dụng không yêu cầu đăng nhập, không có quà tặng trả phí và không kết nối với nền tảng livestream. Nội dung chỉ tồn tại trong phiên trình duyệt hiện tại.

## Chức năng chính

- Giao diện responsive cho mobile, tablet và desktop.
- Chánh điện 3D với nhân vật dâng hương và hiệu ứng ánh sáng.
- Gửi lời nguyện trực tiếp trong website.
- Chat thời gian thực ngay trong chánh điện, với bong bóng tin nhắn đi theo nhân vật dâng hương.
- Điều khiển nhân vật tự do bằng thao tác chạm, WASD hoặc phím mũi tên.
- Dâng hương, hoa sen và đèn tỉnh thức miễn phí.
- Chuông, mõ và bốn không gian nhạc thiền.
- Bảng hoạt động trong phiên và hiệu ứng mưa hoa.

## Chạy dự án

Yêu cầu Node.js 20 trở lên.

```bash
npm install
npm run dev
```

Mở `http://localhost:3000`. Trên Windows có thể chạy `START-WEBSITE.bat`.

## Kiểm tra

```bash
npm run lint
npm run build
```
